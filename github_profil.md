# Kako urediti GitHub profil

GitHub profil je portfolio programerke. Poslodavci ga često pogledaju prije intervjua.

## Šta GitHub profil treba imati

- Profilnu sliku i kratak opis (bio): ko ste i šta vas zanima.
- Profilni README: poseban repozitorij s istim imenom kao vaše korisničko ime, u kojem predstavite sebe, svoje vještine i projekte.
- Prikvačene (pinned) projekte: odaberite najbolje radove da budu prvi na profilu.

## Koliko projekata

Bolje je imati tri do pet urednih, dovršenih projekata nego dvadeset nedovršenih. Kvalitet je važniji od količine.

## Dobar repozitorij

Svaki projekat treba imati README datoteku koja objašnjava šta projekat radi, kako se pokreće i koje tehnologije koristi. Dodajte snimak ekrana ili primjer rezultata. Nikada ne stavljajte lozinke ni API ključeve u repozitorij; koristite .env datoteku i dodajte je u .gitignore.

## Redovnost

Redovni commitovi pokazuju da aktivno radite. Pišite jasne commit poruke, na primjer "Dodana pretraga po ključnim riječima" umjesto "izmjene".
